# Internship Command Center

A free, static internship tracker website. No paid service, account, server, or external library is required.

## Publish it free with GitHub Pages
1. Sign in to GitHub or create a free account at https://github.com.
2. Create a new **public** repository named `internship-command-center`.
3. Upload `index.html` from this folder to the repository's root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then Save.
7. Wait a minute or two. GitHub will show your public website URL in the Pages section. It will look like `https://YOUR-USERNAME.github.io/internship-command-center/`.

## Important data note
This version saves your information in the browser on the device where you use it (local storage). It does not sync between devices or provide a private login. Use **Export backup** regularly and keep the JSON backup somewhere safe. Do not enter passwords, bank details, or other sensitive information.
